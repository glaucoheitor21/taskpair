# Roteiro de apresentação (≈5 minutos)

Para a demonstração do CP5/CP6. Use o APK instalado no celular ou no emulador.

| Tempo | O que mostrar | O que falar |
|---|---|---|
| 0:00 | Ícone e splash | "TaskPair: trabalhos em grupo sem trabalho desigual. No CP4 apresentamos a ideia; hoje é o app funcionando." |
| 0:30 | **Entrar** (modo demonstração ou conta Supabase) | "Login com e-mail e senha, sessão salva. O banco é o Supabase, com segurança por linha: cada pessoa só vê os projetos de que participa." |
| 1:00 | **Início** | "A primeira coisa que o app mostra é quanto do trabalho está com você — e o alerta quando a carga de um projeto está concentrada." |
| 1:30 | Tocar no alerta → **Painel de Equilíbrio** | "Toda tarefa tem peso. O Balance Score vai de 0 a 100; a barra mostra a fatia de cada um. Acima de 15 pontos percentuais do ideal, o app sugere redistribuir — sem acusar ninguém." |
| 2:30 | **Ver quadro** → "Pegar esta tarefa" → "Fazendo →" | "Tarefas sem responsável ficam no pool. Pegar uma muda o Painel na hora." |
| 3:15 | **Nova tarefa** sem peso → erro → preencher | "O peso é obrigatório: é o que diferencia o TaskPair de um Trello." |
| 3:45 | Voltar ao projeto → score mudou | "O cálculo é recalculado sempre, nunca salvo — não existe número desatualizado." |
| 4:15 | **Perfil** → modo escuro | "Contribuição por projeto e o tema escuro que já estava nos tokens do CP4." |
| 4:30 | Repositório: README, `docs/`, `npm test` | "Documentação de telas, testes (35 no Jest), manual de uso, decisões técnicas e o APK nas Releases." |

**Se perguntarem do modelo de negócio:** freemium — ver [`docs/03-pitch-modelo-de-negocio.md`](03-pitch-modelo-de-negocio.md).

**Plano B sem internet:** o APK sem `.env` roda no modo local, com os dados de demonstração no próprio aparelho.
